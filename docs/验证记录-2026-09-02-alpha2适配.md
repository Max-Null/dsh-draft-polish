# 验证记录 — v0.2.2 DSH 0.1.2-alpha.2 兼容适配（2026-09-02）

## 背景

用户环境（SSiD v0.1.17，profile ssid）从 0.1.2-alpha.2 升级到 0.1.2-alpha.4 后出现多个问题，
已回退至 alpha.2（实体 @deepseek-ai/dsh 0.1.2-alpha.2 / .runtime-version 0.1.17-0.1.2-alpha.2-2eb3978c）。
dsh-draft-polish 0.2.1（npm 实体）在 alpha.2 环境**不可用**：点击润色报「未配置模型渠道」、
设置入口消失。本版本适配 alpha.2 契约（并保留 alpha.4 兼容回退）。

## 根因（0.2.1 vs DSH 0.1.2-alpha.2）

| 问题 | 0.2.1 旧实现 | alpha.2 现状 | 后果 |
|---|---|---|---|
| 模型渠道继承 | `connection.api.sessions.models`（RPC） | ISessions 无 `models` 方法（会话模型通道改由 `modelSelection` 投影承载） | 继承恒失败 → provider 空 → host 抛 no-provider → 「未配置模型渠道」 |
| 设置入口 | `settings.section`（General 区 slot） | 已退役；官方为「可配置插件」Tab `settings.plugin.item`（keyed by namespace） | 设置表单无入口 |
| client 模块声明 | `dsh.client.inject` 含 `@deepseek-ai/dsh-client-runtime` | 该模块已从内核移除（client-modules / ui-cordis 替代） | 模块声明失效 |
| 默认渠道兜底 | 无（provider 空直接报错） | 新会话/无请求记录会话 `modelSelection` 投影为 null，继承无源 | 无兜底 |

> 注：alpha.2→alpha.4 之间 `conversation.input.right` 的 `owner: InputZone` 被移除（渲染点移至
> InputBar 内部，`renderSlot('conversation.input.right', {})`），alpha.2/alpha.3 仍有 owner；
> 本适配按**双轨**（标准座 `useInput` 优先 + owner `input` 回退）同时覆盖两代契约。

## 修复内容（v0.2.2）

**client 端**（lib/client.js）：
- `ClientContext` 类型源：`@deepseek-ai/dsh-client-runtime/client` → `@deepseek-ai/cordis`（ctx.slots 合并来自 `dsh-client-ui-renderer` 类型 import）。
- `settings.section` 注册 → `settings.plugin.item`（`key: 'draft-polish'`，官方 keyed 卡片姿势，参照 dsh-node-appearance 0.3.4 已验证范式）；移除旧设置导航图标 hack（settings.section 退役后无此导航行）。
- 草稿读取双轨：`props.useInput(state => state)?.draft`（标准座，两代契约通用）→ 回退 `props.input?.draft`（alpha.2/alpha.3 owner）。
- 模型继承：删 `connection.api.sessions.models` RPC，改读会话标准座 `useProjection('modelSelection')`（`next ?? lastUsed`）。
- `dsh.client.inject` 模块声明：`runtime/locale/ui-slots/ui-conversation` → `ui-renderer / ui-conversation / ui-settings-plugins / ui-session`。

**host 端**（lib/index.js）：
- 默认渠道兜底：`provider/model` 为空时经 `ctx.inject(['agentDefaultModel'])` 读 DSH 默认模型渠道
  （@deepseek-ai/dsh-agent-default-model，会话创建时应用的选择）——解决新会话/无投影记录的场景。

- 环境：SSiD dev（seek-soul-in-darkness/shell，electron . --remote-debugging-port=9222），profile ssid 实体 alpha.2。

- 结果（.tmp-final-polish.mjs 全链路）：
  1. 润色按钮渲染于 `conversation.input.right` 官方座位 ✓（console 无插件错误）
  2. 编辑器注入草稿 → 发送按钮启用（InputState.draft 同步）→ 点击润色 ✓
  3. toast「已润色」+ 润色结果回填输入框 ✓（经 host `/draft-polish/api/polish` → llm）
  4. 验证后输入框清空，无残留 ✓
- 单元/类型：typecheck 0 error；vitest 65/65 通过（client 用例覆盖 useInput 主路径 + owner 回退 + modelSelection 继承；host 用例覆盖默认渠道兜底）。
